# How to open these files as Google Docs

This folder has two documents. Keep them separate.

1. `feature-request-contact-desk.html` — Feature Request
2. `development-plan-contact-desk.html` — Development Plan (after the request is Confirmed)

## Import

1. Open [Google Drive](https://drive.google.com).
2. Click **New** → **File upload**.
3. Upload one HTML file.
4. Right-click the file → **Open with** → **Google Docs**.
5. Click **File** → **Save as Google Docs**.
6. Repeat for the second file.

Do not put the request and the plan on one page.
